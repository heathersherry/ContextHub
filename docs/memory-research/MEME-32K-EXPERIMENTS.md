# MEME-32k 100 例实验索引

Reproduction instructions and pinned historical source tags: [MEME-32k reproduction](../../experiments/meme32k/README.md). Adding this entry point is not a new 100-case experiment.

这里只记录 MEME-32k 版本覆盖全部 100 个 case 的实验，包括完整流程基线和复用保存材料的全量重答。其他 MEME 版本及其他 benchmark 使用各自的索引，不混入本表。最近更新：2026-10-23。精确时间统一用香港时间（UTC+8）。

最近结论：**B 方案把当前事实 JSON 换成原文逐条换行后，100 例总分为 432/694（62.25%），比此前 A 版多 1 题；Agg 为 32/100。历史题增加的 3 分全部来自输入未变的重跑差异，且出现精确复述和旧风格指令干扰的回归，暂不支持直接替换默认格式。成功请求的回答输入 token 减少 24.50%；重试缺失用量，不能直接当作账单降幅。**

| 任务 | A：官方模板 + JSON | B：官方模板 + 原文换行 | 变化 | 题数 |

- **改动和复用范围**：1,088 份当前事实输入去掉 JSON 外壳，以换行连接每条原文；100 份历史输入不变。不删无关材料、不改写或分组，原文内部换行保留。只有回答和评分调用，生产代码和提示词未改。见[方案说明](../../outputs/answer-format-full100-20261023/protocol.txt)、[运行配置](../../outputs/answer-format-full100-20261023/manifest.json)。
- **回答变化**：10 题由未通过变通过，9 题反向变化。Agg 实际补齐了 `pl_003` 的徒步俱乐部、`pl_044` 的跑步俱乐部、`sw_024` 的分支策略及默认分支；`pl_007` 则漏掉了跑步俱乐部。目标项覆盖 198→205/300。15 道值班题仍 0/15，10 道文档题仍 0/10；这些题的范围歧义须另行判断，不能只为覆盖标准答案修改系统。
- **不能算作格式收益的分差**：Tr 的 3 道升分题输入都未变。`pl_026`、`pl_032` 答案也逐字相同，仅 judge 改分；`sw_016` 同样输入下生成顺序发生变化。真正改了排版的 594 道后测按原评分合计 365→363，仅作诊断拆分，不替代官方总分。见[相同答案改分](../../outputs/answer-format-full100-20261023/same-answer-judge-changes.json)、[未改输入的分差](../../outputs/answer-format-full100-20261023/unchanged-input-score-changes.json)。
- **回归与评测疑点**：`sw_003`、`sw_031` 的完整日志在输入中，但回答少了整行；`sw_005` 新增 6 次额外人物点评，A 中没有。部分 Abs/Del 仍拿相近属性代答或生成无依据的值；judge 多次错误地把这些值称为“被删除的旧值”。`pl_012` 回答 apartment 有材料依据，但 gold 要求未知，需另查时间关系，不能直接认定回答胡编。既有 10 项数据冲突照常保留官方判分并单列。见[人工复核](../../outputs/answer-format-full100-20261023/manual-audit.txt)、[退步题](../../outputs/answer-format-full100-20261023/regressions.json)、[数据冲突](../../outputs/answer-format-full100-20261023/dataset-conflicts.json)。
- **耗时、调用与用量**：1,188 次回答、988 次模型评分全部成功，另有 200 道 ER 确定性匹配。3 次回答失败尝试和 10 次 judge 超时均经重试恢复，实际请求分别为 1,191 和 998 次；无最终失败。成功回答的输入 token 953,364→719,833，减少 24.50%；失败尝试缺少用量，不能直接换算完整账单。23.92 分钟，实际请求并发峰值 4。全部实际请求、原始响应和来源哈希核验通过，见[核验汇总](../../outputs/answer-format-full100-20261023/summary.json)。
- **结论**：B 减少了已知输入 token，但本轮没有证明整体质量更好；暂不将其写入默认回答流程。若继续研究，应围绕通用的条目和多行引文边界、事实与旧行为要求的区分开展受控对照，并检查全部题型回归。

Cas、Abs、Del 必须前后测都正确；ER、Agg、Tr 按后测计分。逐题合计与六类等权平均是不同口径，不混用。已知评测数据冲突仍保留官方判分，另外列证据。

- **改了哪里**：[answer_guidance.txt](../../prompts/answer_guidance.txt) 保存完整官方模板；[runner.py](../../integrations/memebench/memory_research/runner.py) 只套用一次，避免重复包模板。实验时的[模板快照](../../outputs/official-answer-replay-20261023/answer_guidance.txt)与[独立代码差异](../../outputs/official-answer-replay-20261023/code-changes.diff)固定保存，今后代码改变也不影响追溯。
- **实际调用**：回答 1,188 次，评分 988 次，全部成功，无重试。ER 使用确定性匹配，不额外调用评分模型。核对确认只有回答和评分请求；原始材料、顺序与冻结来源文件未变。见[核验汇总](../../outputs/official-answer-replay-20261023/verified-summary.json)和[运行配置](../../outputs/official-answer-replay-20261023/manifest.json)。
- **观察到的未覆盖项**：15 道值班题全部未答手册，另有 12 道未答告警；10 道文档题仍只答主文档入口。相关事实已在回答输入中，但后续讨论指出问句与 gold 可能存在范围歧义，不能仅据此认定系统故障。Agg 目标项覆盖为 198/300，原始为 191/300、首版指导为 200/300，不能用部分覆盖代替整题通过率。
- **评分问题**：与两个历史版本对照，有 3 个不同阶段题出现答案相同但判分不同；相对首版指导是 2 题，一升一降。另有日期格式、评分理由不准确等问题，见[人工复核](../../outputs/official-answer-replay-20261023/manual-audit.txt)、[相同答案改分](../../outputs/official-answer-replay-20261023/same-answer-judge-changes.json)和[数据冲突](../../outputs/official-answer-replay-20261023/dataset-conflicts.json)。
- **结论与当前状态**：没有看到这次改动解决代表性聚合遗漏；不能把小幅升降全部归因于模板。按用户要求保留纯官方模板。它统一了与 MD-Flat 的回答提示词，双方的维护模型、材料、检索方式和供应商仍不一致，不能称为完整受控系统对比。

首版通用指导有 1 次回答过滤失败、3 次评分超时重试，详见该轮报告；本次纯官方模板全部调用成功。
